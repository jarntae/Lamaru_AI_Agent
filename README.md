# Lamaru AI Gateway

Local AI Gateway + Agent runtime for VS Code and developer workflows.

## Features & Goals

- Multi-provider support (starting with Google Gemini)
- Multiple API keys and accounts per provider
- Automatic routing, retry, cooldown, and fallback
- Agent runtime preserving state across model switches
- SQLite local persistence
- OpenAI-compatible local HTTP Gateway
